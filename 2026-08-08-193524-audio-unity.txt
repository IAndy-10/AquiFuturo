⏺ The four files that form the complete audio-motion pipeline:

  ---
  1. unity/Assets/Scripts/Audio/PoseAnalyzer.cs

  What it does: Reads the AR camera transform every frame and computes 4 raw
  axes relative to the placed tree, then smooth-damps them.

  ┌────────────────┬────────────────────────────────────────────────────────┐
  │    Output      │                    What it measures                    │
  │    property    │                                                        │
  ├────────────────┼────────────────────────────────────────────────────────┤
  │ Azimuth        │ Horizontal angle from camera forward to the tree       │
  │                │ (degrees)                                              │
  ├────────────────┼────────────────────────────────────────────────────────┤
  │ Alignment      │ How directly you're facing the tree (dot product)      │
  ├────────────────┼────────────────────────────────────────────────────────┤
  │ Tilt           │ Camera pitch — pointing down = underground, up =       │
  │                │ canopy                                                 │
  ├────────────────┼────────────────────────────────────────────────────────┤
  │ Distance       │ Horizontal metres to the tree base                     │
  ├────────────────┼────────────────────────────────────────────────────────┤
  │ Attention      │ Derived from Alignment via logarithmic ramp — drives   │
  │                │ the LPF                                                │
  └────────────────┴────────────────────────────────────────────────────────┘

  ---
  2. unity/Assets/Scripts/Audio/TrackMixer.cs

  What it does: Reads those 4 axes every frame and applies all 4 SPEC §9.3
  mappings to the tracks.

  ┌──────────┬───────────────────────────────────────────────────────────────┐
  │ Mapping  │                       Axis → Parameter                        │
  ├──────────┼───────────────────────────────────────────────────────────────┤
  │ Mapping  │ Attention → LPF cutoff (logarithmic Hz)                       │
  │ 1        │                                                               │
  ├──────────┼───────────────────────────────────────────────────────────────┤
  │ Mapping  │ Azimuth → stereo pan (sine form, per-track width)             │
  │ 2        │                                                               │
  ├──────────┼───────────────────────────────────────────────────────────────┤
  │ Mapping  │ Tilt → per-track gain (tiltBias makes canopy louder when      │
  │ 3        │ pointing up, root_rave louder when pointing down)             │
  ├──────────┼───────────────────────────────────────────────────────────────┤
  │ Mapping  │ Distance → master gain offset + LPF ceiling (both from        │
  │ 4        │ AnimationCurves)                                              │
  └──────────┴───────────────────────────────────────────────────────────────┘

  ---
  3. unity/Assets/Scripts/Core/AudioSettingsConfig.cs + 
  unity/Assets/Settings/AudioSettings.asset

  What it does: All the tunable numbers — cutoff min/max, smooth times, pan
  width multipliers per track, tilt gain range, distance curves, gain clamp.
  Nothing is hardcoded in TrackMixer or PoseAnalyzer.

  ---
  4. unity/Assets/Scripts/Audio/TrackChannel.cs

  What it does: Thin wrapper on each AudioSource + AudioLowPassFilter. Exposes
  SetCutoffHz(), SetPan(), and carries the per-track metadata (TiltBias,
  BaseGainDb) that TrackMixer reads to apply Mapping 3.

  ---
  The data flow in one line:

  iPhone moves → PoseAnalyzer (axes) → TrackMixer (mappings) → TrackChannel × 4
  (LPF + pan + volume)

⏺ Done. Here's exactly what changed and what you need to do in Unity:

  ---
  What changed

  TrackChannel.cs

  - Removed _panWidthIndex (was an index into a shared array — fragile,
  order-dependent)
  - Added _isStatic — when true, TrackMixer skips all modulation: LPF stays
  fully open, pan stays centred, only base gain + mute ramp apply. Set this on
  the drone in the Inspector.
  - Added _lpfSensitivity [0–1] — how deeply attention drives the LPF on this
  track. 1.0 = full 800–20 kHz range. 0.5 = only opens to ~4 kHz.
  - Added _panWidth [0–1] — the track's own spatial width. Pan is the primary
  expressive axis.

  TrackMixer.cs

  - Static tracks: SetCutoffHz(max), SetPan(0), base gain only
  - Active tracks: per-track LpfSensitivity scales effectiveAttention before the
   log cutoff formula; ch.PanWidth replaces the old array lookup
  - Fixed tilt sign bug: was TiltBias * -tilt, now TiltBias * tilt — canopy now
  correctly gets louder when you point the phone up

  AudioSettingsConfig.cs

  - Removed panWidths[] array — each track owns its spatial width directly

  Unity wiring required — set these in the Inspector
